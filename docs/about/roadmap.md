# Roadmap

## Native v1 acceptance

- [x] Multi-Entra identity profiles and explicit scan scope
- [x] Unified Azure VM, Bastion, Arc, and Azure Local inventory
- [x] Separate Azure and target-machine authentication models
- [x] Mapped domain/local/SSH identities and no-password-reprompt RDP staging where Windows permits
- [x] Explicit Arc WindowsOpenSSH preparation
- [x] Notification-area operation, themes, background sync, managed sessions
- [x] Self-contained ZIP and MSI packaging

## Later candidates

- Signed MSIX and enterprise policy templates
- Winget publication and automatic update channel
- Optional diagnostic bundle with strict redaction
- PIM deep links and richer permission diagnostics
- Additional credential providers only after separate security review
