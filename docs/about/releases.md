# Release notes

Stagecoach has not shipped its first release yet — the project is in design
and early build. This page will carry the notes for every tagged release.

## What a release will look like

- Versioned releases are tagged on GitHub and, from Phase 4, published to the
  PowerShell Gallery as the `AzureStagecoach` module.
- Each release gets notes here: what's new, what changed, what to know
  before upgrading.
- The [changelog](./changelog) tracks the running detail between releases;
  release notes are the curated summary.

## Following along

- Watch the [GitHub repository](https://github.com/Hybrid-Solutions-Cloud/stagecoach)
  for tags and releases.
- The [roadmap](./roadmap) shows which phase is in flight right now.
